# Why reading data matters

Before we can analyse biological data, we must load it into Python.
Most bioinformatics data is stored as:

- tab-separated text files (`.tsv`, `.txt`)
- comma-separated files (`.csv`)

These can be read easily using `pandas.read_csv`.

# Reading a table

```python
url = "https://raw.githubusercontent.com/shambam/R_programming_1/main/Mouse_HSPC_reduced.txt"
hspc_data = pd.read_csv(
    url,
    sep="\t",
    header=0,
    index_col=0
)

hspc_data
```

Arguments explained:

- `sep="\t"` → tab-separated file  
- `header=0` → first row contains column names  
- `index_col=0` → first column contains row names (genes)

# Selecting subsets by column name

Select only columns that contain "MEP":

```python
mep_data = hspc_data.loc[:, hspc_data.columns.str.contains("MEP")]
mep_data.head()
```

Select only columns that start with "LTHSC":

```python
lthsc_data = hspc_data.loc[:, hspc_data.columns.str.startswith("LTHSC")]
lthsc_data.head()
```

What have we done right now?
```
?hspc_data.columns.str
```

And see what is defined in this collection:
```
dir(hspc_data.columns.str)
```

# Writing data to a file

Write a DataFrame to a tab-separated file:

```python
lthsc_data.to_csv(
    "LTHSC_data.txt",
    sep="\t",
    index=True,
    header=True
)
```

Write the other subsets:

```python
mep_data.to_csv("MEP_data.txt", sep="\t")
gmp_data.to_csv("GMP_data.txt", sep="\t")
```
